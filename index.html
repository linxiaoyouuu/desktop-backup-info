Desktop Backup

A personal desktop backup utility maintained by linxiaoyouuu, for the owner's use only.

The utility uploads selected local folders to the owner's Google Drive and verifies backup integrity. After a new backup is verified, it can remove the previous backup created by this task.

Google authorization uses the drive.file scope to access files created by or explicitly authorized for this application.

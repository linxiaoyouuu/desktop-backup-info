Desktop Backup Privacy Policy

Last updated: November 20, 2026.

Desktop Backup is a personal utility used by its owner to back up selected local files to their own Google Drive.

Data and access

The utility reads selected local files and file metadata to create and verify backup archives. It uses the Google Drive drive.file permission to create and manage files created by or explicitly authorized for this application. It does not request access to all existing Drive files.

Use and storage

Backup archives are stored locally and in the owner's Google Drive. OAuth credentials and tokens are stored locally for scheduled access. File information and transfer errors may appear in local logs. Google processes uploaded data according to its policies.

Sharing

The utility does not sell data, use it for advertising, or send backup contents to AI models. Backup contents are transmitted to Google Drive for storage. This informational website does not receive backup files or OAuth credentials.

Retention and control

After a new backup is successfully verified, the previous task-generated cloud backup may be permanently deleted under the owner's configured retention policy. Local archives may remain until removed. The owner can stop scheduled backups, revoke access through Google Account settings, and delete local and cloud data. Revoking authorization does not itself delete existing backups.

Google API data

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
